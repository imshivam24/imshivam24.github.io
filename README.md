# Shivam Chaturvedi — Personal Academic Website

Source for [imshivam24.github.io](https://imshivam24.github.io): research, publications, presentations, teaching, and gallery of Shivam Chaturvedi, Ph.D. candidate in Chemical Engineering at the Indian Institute of Science, Bangalore.

## Contents

| Path | What it holds |
| --- | --- |
| `_pages/` | About, CV redirect, Research, Presentations, Teaching, Gallery, Publications |
| `_bibliography/papers.bib` | Publications (BibTeX, rendered by jekyll-scholar) |
| `_news/` | Announcements shown on the home page |
| `_projects/` | Research project cards |
| `assets/pdf/` | Current CV |
| `assets/img/` | Photos, figures, and gallery images |

## Run locally

```bash
bundle install
bundle exec jekyll serve
```

The site is then available at `http://localhost:4000`. See [INSTALL.md](INSTALL.md) for the Docker-based setup.
